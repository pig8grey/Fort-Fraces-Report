Note to Readers:

Dynamic displacement is obtained by integration of velocity data from the sensors. Symroc selected strong motion sensor based on the strong train load impact, the sensors installed have accurate displacement measurement down to 0.3Hz. The system has been tested with comparison of LVDT type of measurement and found the magnitude of the displacement to be accurate using shaker table comparison at 0.3Hz, 0.4Hz, 0.5Hz….. 1Hz, 2Hz …. interval test points to the higher frequency range and has demonstrated reliable results in various field settings. The systems are capable to obtain dynamic displacement of subject bridge at any location of the bridge – where LVDTs or Displacement transducers requires scaffold or rigid support that is not moving with respect to the subject bridge.

What is in this report

In this report, an event is defined as the difference of the measured min and max dynamic displacement exceeds 0.1 mm for top sensors, 0.03 mm for bottom sensors.

  • Table 1 – Daily substantial events: Table containing events triggered at similar times by all sensors.
  • Table 2 – Daily Events Triggered by Top Sensors Dynamic Displacements (mm): Table containing events triggered at similar times by the top two sensors at minimum but not all.
  • Table 2a – Daily Events Triggered by the Bottom East or Bottom West Sensor Dynamic Displacements (mm): Table containing events triggered by the Bottom East Sensor
  • Table 3 – Daily Maximum Total (Max-Min): Containing the result of all the difference in maximum dynamic displacement and the minimum since the beginning of the recording date. Starting in July 19,2023, the reported values are no longer daily max-daily min, but using max-min from each event then report the largest value
